lightbulb JSONPath Help & Examples

JSONPath allows you to filter and extract data from your JSON structure. Below are common patterns used in this application:

$.[*].services[*].companyShareAmount
Extracts the companyShareAmount from every service in the list.
$.[*].services[*].['companyShareAmount', 'companyTax']
Extracts both fields simultaneously. Useful for calculating total costs (Sum/Avg).
$.[*].services[?(@.lineItemNo==1)]...
Filters services where lineItemNo is 1, then dives into packageDetails to get share and tax.
Quick Tips:
  • $ represents the root object or array.
  • [*] iterates over all items in an array.
  • ?(@.field == val) filters items based on a condition.
  • ['a', 'b'] selects multiple properties (Union).
